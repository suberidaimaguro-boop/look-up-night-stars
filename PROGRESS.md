# Star-sky PWA "見上げてごらん　夜の星を" — status & handoff notes (as of 2026-11-01)

Vanilla JS + canvas PWA, no build step. User-facing text is Japanese; this file is English for lower token cost.
Read the "Gotchas" section before changing anything.

## Deploy
1. Overwrite app files: index.html, style.css, app.js, data.js, stars_extra.js, myths.js, art.js, sw.js, manifest.json, icon.png, icon-192.png.
2. Put the 36 art/*.webp files in an `art/` folder next to them.
3. **If any file in sw.js CORE is missing on the server, SW install fails (offline breaks).** Art files missing on the server are only skipped. When adding files, update CORE/ART and bump V.
4. After publishing, reload 1–2 times on the device to pick up the new SW. To change the iPhone home-screen name, delete and re-add the icon.

## Current behavior (spec)
- **Data**: 58 constellations with lines, 536 named/info stars (distance + spectral type for 510, from HYG v4.1), plus ~8,300 faint stars. Stars without a Japanese name show like "ケフェウス座ε星"; all 536 show Japanese names.
- **Constellation list UI** (settings → 星座の一覧と神話): search, filters (all / visible now / myth / modern), tap → myth card, highlighted lines, jump to position; "空でその星座を見る" / "見える日時にする".
- **Defaults**: star names off, FOV 80° (gyro: 55°), gyro on, faint limit 6.3 mag, art mode 'sel' (tapped constellation only), intro message on.
- **Settings migration**: `stored.ver` (now 4). ver2: names off/FOV80/gyro on; ver3: limit 6.3; ver4: art mode 'sel'. Each runs once; other settings kept.
- **Immersive mode**: tapping empty sky hides top bar + settings; auto-hides after 10 s idle (setting, default on); hidden when gyro starts; a thin line at bottom brings it back. Open cards are never hidden.
- **Gyro**: iOS needs a tap for permission (requestPermission works only inside click/touchend). A tap during the intro message is accepted immediately and also dismisses the message. Android uses `deviceorientationabsolute` first, falls back to normal events after 2 s; auto-on only when sensor values actually arrive. PC: always off. Turning gyro off saves gyro:0.
- **Azimuth reset**: bottom-right button while gyro is on; clears the drag correction (arOff). arOff also resets to 0 each time gyro starts.
- **Intro message**: "カーテンを閉めたままでも、シャッターを閉めたままでも、いつでも星を見ることができます。" Mincho font (system), per-character fade-in, auto-dismiss at ~3 s with a drift-up/blur exit (~1.5 s), tap to skip, "次回から表示しない" button, settings toggle (clear settings restores it). Shortened under prefers-reduced-motion. (The old iOS hint "画面をタップすると…" under the message and its toast were removed in v25; the first tap still requests sensor permission silently.)
- **Constellation art**: drawn under star lines with additive blending (black = transparent), only at night (factor `1-tw`, twilight). Modes: 'sel' (default), 'all', 'off'; top-bar "星座絵" button toggles all/sel. Tapping a constellation name (✦ marks ones with art) shows its art + myth card; tapping again hides it; closing the myth card keeps the art. Star taps win over name taps only when not on a label. First-time hint about tapping names.
- **Performance** (frame ≈12 ms → ≈2 ms on PC; 4× CPU throttle ≈59 → ≈8 ms): star positions recomputed only when time (≥2 s)/place/limit change; frustum culling via stored unit vectors; faint stars batched as rects by color/brightness; per-star color/radius cached; off-screen art skipped; intro blur applied per line, not per character.

## Adding constellation art (procedure)
1. Make a black-background image with no stars/text; convert to 768px WebP (q≈80).
2. Pick 3–11 anchors: image points (u,v in 0–1) ↔ real stars. For 2-star constellations 2 anchors work (artFit allows `min(3, n)`).
3. Choose the assignment by brute-force fit (similarity transform, flip 0/1; minimize rms with sensible scale ≈15–40° per image width; then check semantics), and verify by screenshot. Optional 4th element = weight (e.g. 2 for the bright star).
4. Add entry to art.js, image to art/, add to sw.js ART array, bump V, update the table above.
- artFit needs ≥ `min(3,n)` anchors above the horizon and ≥ 60% of anchors visible, otherwise the art is hidden (so art does not vanish abruptly as a constellation sets).

## Fast integration workflow (what worked; ≈10 tool calls per batch of 3 images)
0. **Inputs**: the images + which constellation each is + the user's latest art.js (and PROGRESS.md). Always start from the user's latest uploaded files (names carry random suffixes, e.g. art_cea5f8.js); write outputs under the plain names (art.js, PROGRESS.md, ...). **sw.js**: if only V changes, do NOT output it (user preference; just tell them the new V). If F changes (new images), output it — if their copy is not provided, rebuild it from the file list in the table above (same body as before: install/activate/fetch handlers) and say so.
1. **Pattern data**: load data.js in node (`global.window=global; eval(src.replace(/\bconst (STAR_DATA|JA|INFO|CONS|CITIES)\b/g,'var $1'))`). Project each constellation's stars around its centroid with the app's orientation (east = left, y down): `x=-k*(v·east)`, `y=-k*(v·north)`, `k=2/(1+v·c)`; save `{stars:{key:[x,y]},lines}` to JSON. Print offsets in degrees + lines, then decide the semantic mapping (head→tail axis, which star is which body part, px per degree ≈ pattern length vs figure length; art is usually 25–50° wide).
2. **Pixel coordinates**: draw a labelled 100 px grid on the 1254 px images, montage 2×2 at 640 px each (displayed scale ≈ 0.4355 → original = display/0.4355; subtract the cell origin), view once, write anchors in original px.
3. **Fit**: weighted similarity least squares (complex form; `flip` = negate image y first), try flip 0 and 1; print rms (px), share of stars inside the silhouette (luminance > 35, close + fill holes), px per degree; draw an overlay (lines, stars, green nominal anchors) at 640 px and view both flips side by side. Choose by overlay + rms; if a body part is clearly off, move that anchor and refit (1–2 rounds). Collinear anchors (≤4 near-line stars, e.g. Ari) do not fix the flip; pick by rms.
4. **Entries**: normalize (px/1254, 4 decimals), keep the fixed anchors at their nominal positions (the app re-fits them), add derived anchors = remaining stars whose fitted position falls inside the dilated silhouette. **Skip stars that are (almost) never visible from Japan (dec < −52°)**, otherwise the 60% visibility rule hides the art (see Cen); prefer anchors that are above the horizon together.
5. **Files**: 768 px WebP q80 (≈50–75 KB) → art/; append to art.js; add to sw.js F (+bump V); update this file (table, counts, anchor notes, history).
6. **Test**: Playwright, TZ Asia/Tokyo, localStorage `{ver:4,art:'sel',gyro:0,auto:0,hint:1,intro:0}`; set date/time near culmination; open the list (`#panel` open → `#conOpen`) → click `#conUl button[data-c="XXX"]` → close the myth card (`#mythClose`) → the art must stay; compare mean brightness of the sky crop before/after and view a montage. For label taps, expose `conHits` in a test copy (`window.__hits=()=>conHits`). Art images missing from the sandbox give 404 (expected).
7. **Pitfalls**: `<(...)` process substitution does not work in /bin/sh; `cut -c` cuts UTF-8 mid-character; do not reuse existing function names (`conAt`); montage cells are 546 px on screen for 1254 px originals.

## Anchor notes per art (fit quality; rms in image-width units)
- Cyg, Ori, Sco (Sco flipped), Cas (W stars → hands/knees/belt; flips upside-down during the night like the real sky), Tau (Aldebaran = eye, Elnath/ζ Tau = horn tips; horn tips slightly off), UMa (Big Dipper handle = tail), Leo (sickle = mane), Peg (square = wings/body; art is ~70° wide and overlaps others in 'all' mode), Lyr (parallelogram = body), Aql (Altair = neck).
- Gem (flip, ~23° wide, rms ≈0.05), CMa (flip, ~28°, rms 0.05), CMi (flip, 2 anchors, ~12°; small like the real one).
- Aur (no flip, 5 anchors, rms 0.035; Elnath shared with Tau), Vir (flip, 5 anchors, rms 0.063, ~50° wide, looks sideways), Sgr (flip, 11 anchors, rms 0.125 numerically but visually the centaur sits well on the teapot/bow).
- Per (no flip, 6 fixed + 8 derived anchors, ~25° wide): head = Gamma Per, sword arm = Lambda/Mu/48 Per (they land slightly left of the raised arm), Medusa-head hand = Theta Per, feet = Zeta/Omicron Per. The Algol cluster lands near the right hip, not on the Medusa head; Miram/Phi Per run off the top of the figure.
- And (no flip, 4 fixed + 4 derived anchors, ~31° wide): head = Alpheratz, chest = Delta And, hips = Mirach, feet = Almach; Eta/Zeta/Epsilon And fall along the right arm. The Pi–Iota–Omicron chain and the Mirach–Mu–Nu–Phi–51 chain lie outside the figure (the real pattern's arms are longer than the art's).
- Her (flip, 7 anchors, rms 0.096, ~43° wide, rotated ~43°, so it looks tilted/upside-down like the real sky): Rasalgethi = lion-skin head, Sarin = face, Kornephoros = lion paw on shoulder, Epsilon Her = chest, Eta Her = belt, Zeta/Pi Her = hips. The keystone is not human-shaped, so rms is the highest of all art; visually the torso sits on the keystone. Overlaps Oph/Ser area in 'all' mode.
- Oph (no flip, 9 anchors, rms 0.061, ~57° wide, upright): Rasalhague = head, Cebalrai/Kappa Oph = shoulders, Marfik = fist on snake, Yed Prior = hip, Zeta Oph/Sabik = knees, Theta Oph = foot, Nu Oph = snake coil. Very large (Ophiuchus is huge); overlaps Her/Sco/Lib art in 'all' mode.
- Boo (no flip, only 5 stars in data, rms 0.036, ~43° wide): Nekkar = head, Seginus = shoulder, Izar = belt, Arcturus = right knee (weight 2), Muphrid = dog's body. With 5 anchors many fits scored equally, so this is chosen by meaning; staff and dogs are not constrained and look tilted at some hours.
- Cep (flip, 9 anchors, rms 0.146 = worst of all art, ~31° wide, appears upside-down in the north sky like the real one): Errai = crown, Alfirk = shoulder, Iota Cep = head, Alderamin = clasp, Eta Cep = scepter hand, Zeta/Delta/Epsilon/Garnet Star = belt/hip/armrest/knee. The throne is dense and bright. Stars sit on the figure but not on specific features.
- Lib (no flip, 6 anchors, rms 0.112, ~30° wide, upright): Zubenelgenubi/Zubenelhakrabi = right/left scale pans (weight 2), Zubeneschamali = chest, Brachium = knee, Upsilon/Tau Lib = skirt. Only the pans are tightly matched.
- Cap (flip, 8 anchors, rms 0.103, ~31° wide): Prima Giedi/Dabih = horn tip/base, Psi/Omega Cap = mane, Zeta/Theta Cap = belly/back, Nashira/Deneb Algedi = tail. Good visual fit.
- Aqr (no flip, 10 anchors, rms 0.114, ~44° wide): Sadalsuud/Sadalmelik = shoulder/hand, Sadachbia/Zeta1/Eta Aqr = jar, Lambda/Psi2/88/104 Aqr = water stream. The stream stars follow the water.
- Psc (no flip, 9 anchors, rms 0.148, ~47° wide): Phi/Tau Psc = northern fish, Gamma/Theta Psc = western fish head/ribbon, Epsilon/Omega/Omicron/Eta Psc = ribbon, Alrescha = knot. Two fish sit on the V shape; the ribbon is not tightly matched.
- Ari (flip, only 4 stars in a near-line, ~30° wide, rms 20 px): Mesarthim/Sheratan = head/neck, Hamal = withers, 41 Ari = rump. Anchors were placed on a head→rump line at the real spacing (px per degree ≈ 42), so flip 0/1 scored almost the same; flip 1 chosen by lower rms. The horns/legs are not constrained.
- Cet (no flip, 6 fixed + 6 derived anchors, ~44° wide, rms ≈ 260 px): head pentagon (Menkar, Kaffaljidhma, Lambda, Mu, Xi2, Nu) on the open mouth/head, Delta–Mira–Baten Kaitos along the body, Tau Cet → Diphda into the tail stock. Deneb Kaitos Shemali and the Dheneb–Theta loop (the fins in the real pattern) float above the tail; the art's fins are lower.
- Cen (no flip, 8 anchors + 1 derived, ~33° wide, rms ≈ 90 px, upright like the figure): Iota Cen = head, Menkent = staff-side shoulder, Nu Cen = chest, Eta Cen = staff, Zeta Cen = horse chest, Muhlifain/Sigma/Delta Cen = back/rump. **Only stars that rise at lat 36° are used as anchors** (Hadar, Rigil Kent, Epsilon, Pi, Omicron1 Cen are never or barely visible); the art is visible only for ~2 hours around culmination (Apr–Jun evenings) and low (≤17°) in the south. Its name label rarely shows (needs 60% of ALL 16 stars up), so reach it from the list or 'all' mode.
- Cru (no flip — symmetric, 4 anchors, rms 0.035, only ~6° wide, tiny): Gacrux = top, Acrux = foot, Mimosa/Imai = left/right arms. **All four stars are below dec −57°, so the art never shows at Saitama (needs ≥60% of anchors up) and only barely in Okinawa (Acrux ≤ 3° high at lat 24°).** Verified at a test latitude of 15°. Reach it from the list/'all' mode only in far-south locations.
- Cnc (no flip, 5 anchors, rms 0.026, ~25° wide, upright): Asellus Australis/Borealis = carapace centre/top, Iota Cnc = upper claw tip, Beta Cnc/Acubens = lower legs. Good fit (the faint constellation gets a clear shape).
- UMi (flip, 7 anchors, rms 0.071, ~28° wide, rotated −104°): Polaris/Yildun/Epsilon UMi = tail tip/mid/base, Zeta/Eta UMi = back/belly, Pherkad/Kochab = chest/shoulder (the bowl is the body; the head is not constrained). Bear stands head-up-left with the tail down to Polaris at 22:00 in June. Picked over a head-mapped fit (rms 0.050) because the bowl-as-body reading is the traditional figure.
- CrB (no flip, 7 anchors, rms 0.069, ~13° wide, rotated ~7°): Theta CrB = centre top jewel, Nusakan = centre pendant, Alphecca = big centre band gem (weight 2), Gamma/Delta/Epsilon CrB = band gems to the left, Iota CrB = far-left peak. Many fits tied; this one keeps the brightest star on the central gem. Only half of the crown is constrained, the rest sits to one side.
- Del (no flip, 5 anchors, rms 0.040, ~6° wide = tiny, upright): diamond stars on the head/back/body, Epsilon Del = tail fluke. Small like the real constellation.
- Sge (no flip, 4 anchors, rms 0.055, ~4° wide = tiny, rotated ~65°): Gamma Sge = arrow tip (weight 2), Delta Sge = shaft, Sham/Beta Sge = fletching. A tighter fit (rms 0.043) existed but put Gamma on the shaft, not the tip.
- Dra (flip, 13 anchors, rms ≈0.14, ~49° wide): **mapped by arc length, not by feature**. The four head-quadrilateral stars (Eltanin/Rastaban/Nu2/Grumium) go on the head/eye/horn/jaw; the spine chain Altais→Phi→Zeta→Eta→Theta→Edasich→Thuban→Kappa→Giausar is spread over 20–60% of a digitised spine polyline of the image (head→tail), proportional to the chain's distance in the sky (scratch `fitdra.js`). The real chain doubles back, the art's spine does not, so rms is high; visually the head sits at Eltanin near Hercules and the tail curls toward the Little Bear (as in the sky). The tail tip extends beyond the last star. Use this arc-length method for other long winding figures.
- Gem/CMa/Vir appear sideways or upside-down depending on sky orientation (same as the real sky).

## Gotchas
- `nightK` is a twilight factor, ~0 at night: art uses `artK = 1 - tw`.
- `S` (settings) is inside an IIFE; tests must use localStorage or a debug hook. Headless Chromium exposes `DeviceOrientationEvent.requestPermission`; stub it for gyro tests.
- `conAt` (constellation center position) is an existing function; the label hit-test functions are `conLabelAt` / `tapCon` — do not reuse the name.
- Faint star names overlap constellation names when zoomed in (FOV < 70°) with star names on (e.g., Cepheus vs Alderamin).
- Playwright test setup that works: timezoneId 'Asia/Tokyo', localStorage `{az,alt,fov,gyro:0,auto:0,intro:0,hint:1,art:'all',ver:4}`, set date/time via inputs, file:// URLs. ERR_FILE_NOT_FOUND for art images that are not in the sandbox is expected.

## Known issues / unverified
- Real-device checks: gyro/azimuth confirmed working by the user (2026-11-01). Not yet reported: intro font look, performance feel, art look on iPhone, tap ease of constellation names.
- Landscape myth card needs scrolling to reach the visibility info and buttons.
- Stars with no distance: Mu Sgr, Omicron1 Cen, z2/y/x Car, Garnet Star, 3 Pup. No detail: Rasalgethi, Alula Australis. Distances beyond several hundred ly are rounded with "約" (Mirfak 510 ly vs ~590 ly elsewhere).
- Constellation line detail is uneven (CMa 4 lines, CMi 1, Boo 4, Vir 4 ...).
- Myth/origin texts were rewritten by me (traditions vary; not checked against sources). ~70 added Japanese star names come from the catalog; 13 are my katakana renderings (Avior, Menkent, Navi, Homam, Dschubba, Tejat, Mahasim, Tianguan, Algenubi, Imai, Muhlifain, Regor, Errai), reading variants unchecked.
- If art feels heavy with many images: default to 'sel' (already), or shrink images to 512px.
- Ideas not requested: planets/Milky Way, red night mode, star-name option for 1st-magnitude only (user said not now).
